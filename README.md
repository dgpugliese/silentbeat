# SilentBeat

An honest dead man's switch. Encrypted in your browser. Released only if you stop checking in.

## Architecture (target)

- **Cloudflare Workers** — API + static asset serving (`worker/`)
- **D1** — relational state (`migrations/`)
- **Durable Objects** — per-switch timer with `setAlarm()` (`worker/src/do/SwitchTimer.ts`)
- **Cron Triggers** — backup expiry sweeper, every 5 min (`worker/src/cron.ts`)
- **R2** — encrypted payload blobs
- **KV** — sessions
- **Static frontend** — `web/`, served via Workers Assets

## Trust model

**Variant A — recipient-held share.** The payload symmetric key is split into two shares. Share A lives on our server and rotates on every check-in. Share B is generated by the recipient's browser at enrollment and never touches our server in plaintext. Neither half decrypts alone.

This means SilentBeat cannot read the payload — not at rest, not at release. The cost: the recipient must enroll at switch creation and retain a rescue file for the lifetime of the switch. If they lose it, the payload is unrecoverable. By design.

See `web/index.html` for the public-facing trust statement.

## Layout

```
silentbeat/
├── web/              # static frontend (landing, app, log)
├── worker/src/       # Cloudflare Worker (Hono router, DOs, cron)
├── migrations/       # D1 schema migrations
├── design/           # original Claude Design wireframe bundle (reference)
├── wrangler.toml

```

## Local dev

```bash
npm install
npm run db:migrate:local
npm run dev
```

Wireframes from the design bundle can be browsed by serving `design/project/`:

```bash
cd design/project && python3 -m http.server 8080
# http://localhost:8080/SilentBeat%20Wireframes.html
```
